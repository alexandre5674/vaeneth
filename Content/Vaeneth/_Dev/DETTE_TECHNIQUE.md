# Dette technique

## 2026-09-17 — PROMPT 7.2

### Distance Matching de l'atterrissage

Le Distance Matching prévu dans le PROMPT 7.2 est reporté au palier 1.

Raison : cette fonctionnalité améliore principalement le confort visuel de l'atterrissage et ne bloque pas la locomotion ni l'intégration du combat. Sa mise en œuvre nécessitera le plugin Motion Warping ainsi que des courbes de distance dans les animations.

Le report est volontaire afin de traiter d'abord le système de combat et les besoins d'animation associés.
